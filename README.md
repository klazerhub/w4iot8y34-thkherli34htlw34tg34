# Расчет кабельных барабанов

Статический калькулятор намотки кабеля: справочник барабанов, подбор типоразмера, распределение заказа и интерактивная 3D-модель. Интерфейс на русском языке, адаптирован для смартфона.

## Загрузка на GitHub

1. Распакуйте архив `drum-calculator-github.zip` на компьютере.
2. Создайте новый репозиторий на GitHub. Для простой публикации выберите **Public**.
3. В репозитории нажмите **Add file → Upload files**.
4. Загрузите содержимое распакованной папки: `index.html`, `assets`, `favicon.ico`, `site.webmanifest`, `README.md` и `.nojekyll`. Загружайте именно содержимое, чтобы `index.html` оказался в корне репозитория.
5. Нажмите **Commit changes**. Если в репозитории уже есть другой `index.html`, замените его новым; замените также файлы иконок с теми же именами.
6. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
7. После завершения публикации откройте адрес, указанный в разделе Pages. Пример: `https://USERNAME.github.io/REPOSITORY/`.

Если при создании репозитория вы не включили **Add README**, это не мешает загрузке: README уже входит в комплект.

## Файлы

- `index.html` — интерфейс, CSS, расчетный код и встроенный 3D-модуль. Сборка и npm не требуются.
- `assets/icons/` — локальные SVG-иконки кнопок и разделов, favicon и PNG-иконки 180, 192 и 512 пикселей.
- `favicon.ico` — значок вкладки браузера.
- `site.webmanifest` — название и иконки для добавления сайта на главный экран, когда браузер поддерживает эту функцию. Автономное кеширование не настроено.
- `.nojekyll` — публикация обычных статических файлов.

Все адреса ресурсов относительные: поддерживаются как корневой сайт, так и сайт репозитория с адресом `/REPOSITORY/`.

## Локальный запуск

Распакуйте весь комплект и откройте `index.html` современным браузером. Для проверки через локальный сервер, если установлен Python:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для 3D требуется WebGL. Внешние ссылки на стандарты открываются отдельно; для вычислений и 3D загрузка с CDN не требуется.

## Изменения

Расчетные скрипты и встроенный 3D-модуль сохранены без изменений. Добавлены иконки, метаданные и файлы для статической публикации. Параметры и результаты рассчитываются в браузере.

## Сторонний код

Исходный HTML включает Three.js. Встроенные уведомления об авторских правах и лицензиях сохранены внутри `index.html`. Иконки интерфейса созданы для этого комплекта.
